Run `npm run build` first, then `node scripts/record-season-demo.mjs` with existing Chrome, FFmpeg and FFprobe. `CHROME_PATH`, `FFMPEG_PATH`, `FFPROBE_PATH` may point to existing installations. The recorder starts/stops a temporary loopback server and new browser context. By default, video/evidence goes outside the code folder; `SEASON_RECORDING_DIR` can choose another local folder. It installs nothing and uploads nothing. Preserve a reviewed take before rerunning.

The recording retains actual CDP viewport updates in their observed order and wall-clock dwell times, without cuts, time compression, fabricated success screens or mocked tool returns. Original reference API calls are aborted so the original historical-reference fallback is visibly used. This is not a claim of successful external data retrieval. The no-match case is a genuine valid rules result. English captions are a labelled recording overlay, not model output.
